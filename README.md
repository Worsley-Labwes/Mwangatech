# Mwangatech website

Single-file static site (HTML, CSS, JS). No build step.

Run: open this folder in VS Code, install "Live Server", right-click index.html > Open with Live Server.

Edit: search for "Mwangatech" (name), "wa.me" (WhatsApp numbers; the form uses PRIMARY in the bottom script), "Selected work" (projects), --sun / --cy / --bg (colours).
